Boss Raid

Programar em equipe vira uma batalha cooperativa dentro do VS Code. Crie uma sala, compartilhe o código e transforme o progresso no editor em ataques contra um boss.

TypeScript VS Code API Socket.IO Node.js
Por dentro do projeto +

O problema e a solução

Explorar a gamificação da programação com uma experiência cooperativa integrada ao ambiente de desenvolvimento.

Conceitos trabalhados

  • Ciclo de vida de extensões, comandos, painéis Webview e comunicação entre interface e extensão.
  • Eventos do editor, acompanhamento de alterações em documentos e descarte de listeners com Disposable.
  • Comunicação em tempo real com Socket.IO e servidor Node.js com Express.
  • Protocolo compartilhado com tipos e uniões discriminadas em TypeScript.
  • Gerenciamento de salas, sincronização de estado, contribuição por jogador, dano e estados de vitória ou derrota.
  • Separação cliente/servidor, testes de regras de dano e salas, compilação e empacotamento VSIX.

Como experimentar

Baixe o arquivo e, no VS Code, use “Extensions: Install from VSIX…” na paleta de comandos. Abra Boss Raid na barra lateral. Requer VS Code 1.132.0 ou superior, conforme o pacote.

O multiplayer depende do servidor configurado. As salas são temporárias e não persistem após reinícios do servidor.
